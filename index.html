Informasi Lembaga TPA

📖 Panduan Lengkap Pengelolaan & Kustomisasi SikadTPA

Panduan interaktif langkah demi langkah untuk mengelola data lembaga, santri, SPP, honor pengajar, mutasi kas, hingga pengubahan tema warna tanpa monoton.

1
Mengubah Profil & Data Lembaga TPA
Identitas lembaga akan otomatis muncul di seluruh Kop Laporan Cetak Resmi, Kwitansi SPP, QRIS, dan pesan WhatsApp wali santri:
  • Melalui Web UI: Buka menu Santri & Ustadz lalu scroll ke card Informasi Lembaga TPA di sisi kanan. Isi Nama TPA, Masjid naungan, Alamat lengkap, No Rekening donasi, Nama Ketua, dan Nama Bendahara. Klik Simpan Perubahan Profil.
  • Melalui File Kode: Buka berkas js/data.js dan sesuaikan nilai properti di dalam objek DEFAULT_DATA.tpaInfo.
2
Mengubah & Menambah Santri serta SPP
Setiap santri memiliki pencatatan SPP bulanan dan buku tabungan digital terpisah:
  • Tambah Santri: Di menu Santri & Ustadz, klik tombol ➕ Tambah Santri. Isi NIS, Nama Santri, Kelas/Jilid, Wali, No WA wali (format 628xxxx), dan tarif SPP.
  • Beasiswa Yatim / Dhuafa: Centang opsi Santri Penerima Beasiswa / Yatim agar status SPP santri otomatis Rp 0 (Lunas Gratis).
  • Pencatatan Pembayaran: Buka menu SPP & Syahriah, klik Bayar pada santri, lalu cetak bukti kwitansi atau kirim struk instan ke WhatsApp.
  • Melalui File Kode: Buka js/data.js pada array DEFAULT_DATA.students.
3
Mengatur Guru / Ustadz & Bisyarah
Pengelolaan pengajar tahsin, jilid iqro, hafalan doa harian, dan pencatatan honor:
  • Melalui Web UI: Buka menu Bisyarah & Operasional. Anda dapat memantau daftar ustadz, jumlah kehadiran/sesi mengajar, serta membayarkan honor bulanan dengan mengklik tombol Bayar Bisyarah (otomatis mengurangi Kas Operasional).
  • Melalui File Kode: Tambah atau ubah pengajar di file js/data.js pada array DEFAULT_DATA.teachers (termasuk baseSalary dan perannya).
4
Manajemen 4 Kantong Kas Amanah
SikadTPA memisahkan kas untuk menjaga kepatuhan syariah dan akuntabilitas:
  • Kas Operasional: Berisi dana SPP untuk honor guru, listrik, ATK, dan modul.
  • Kas Tabungan Santri: Dana amanah murni titipan uang saku santri. Dilarang terpakai untuk operasional.
  • Kas Infaq & Sedekah: Kotak amal Jumat santri, fidyah, dan infaq sukarela.
  • Kas Sarana & Pembangunan: Renovasi ruang kelas, pengadaan karpet, meja Al-Qur'an, dan inventaris.
  • Melalui File Kode: Buka js/data.js pada array DEFAULT_DATA.wallets.
5
Mengubah Tema Warna Tampilan
Tersedia 5 tema tampilan modern agar tidak monoton dan tampak segar:
  • Royal Sapphire: Perpaduan biru safir navy mewah & emas sampanye (default baru).
  • Persian Turquoise: Toska mozaik masjid Samarkand & coral oranye hangat.
  • Moroccan Terracotta: Warna tanah liat terakota artisan membumi.
  • Obsidian Midnight Dark: Mode gelap futuristik dengan aksen neon cyan.
  • Classic Emerald: Hijau zamrud klasik islami.
  • Cara Cepat: Klik tombol pemilih tema di bilah atas (header kanan). Pilihan tersimpan otomatis di browser Anda.
6
Cadangkan (Backup) & Pulihkan Data
Karena aplikasi menyimpan data secara lokal di browser, Anda disarankan rutin membuat backup:
  • Unduh Cadangan: Buka menu Laporan Keuangan lalu klik Backup JSON. File data akan terunduh ke komputer Anda.
  • Pulihkan Data: Klik tombol Restore Data dan pilih berkas backup JSON Anda jika berpindah laptop atau komputer.
  • Reset Contoh: Tombol Reset Sample akan mengembalikan seluruh data ke data awal bawaan jika Anda ingin memulai dari nol.

📖 Panduan Kustomisasi & Pengubahan Isi

1
Mengubah Profil Lembaga TPA
Buka menu Santri & Ustadz -> Formulir Informasi Lembaga TPA. Masukkan Nama TPA, Masjid, Alamat, Rekening Bank, Nama Ketua, dan Nama Bendahara. Data ini otomatis digunakan di seluruh Kop Laporan PDF/Cetak, Kwitansi, dan format WhatsApp.

2
Mengubah & Menambah Santri serta SPP
Buka menu Santri & Ustadz -> Klik tombol ➕ Tambah Santri. Masukkan NIS, Nama, Kelas, No WA Wali, dan tarif SPP. Santri beasiswa yatim/dhuafa dapat dicentang agar gratis SPP.

3
Mengubah Tema Tampilan
Klik tombol 🎨 [Nama Tema] di pojok kanan atas untuk memilih salah satu dari 5 tema visual eksklusif: Royal Sapphire, Persian Turquoise, Moroccan Terracotta, Obsidian Midnight, atau Classic Emerald. Pilihan tema tersimpan otomatis di browser.
4
Pengubahan Langsung di Kode Sumber
Jika ingin mengubah data default secara permanen:
  • File js/data.js: Objek DEFAULT_DATA (tpaInfo, students, teachers, wallets, transactions).
  • File css/style.css: Pengaturan warna tema di :root dan [data-theme="..."].
  • File index.html: Judul web, logo brand, dan struktur teks statis.
